# KAMITSUBAKI Wiki

非公式の多言語ファン百科です。Node.js 22、pnpm 11.1.1 を使用し、`pnpm install --frozen-lockfile` で導入します。

[開発・貢献手順](CONTRIBUTING.md) と [保守コマンド](maintenance/README.md) を参照してください。[閲覧ガイド](docs/manuals/site/start/ja.md)・[投稿ガイド](docs/manuals/contribute/start/ja.md) も利用できます。本番は main と `node scripts/release-build.mjs` を使用し、確定した候補版への明示的な承認が必要です。
