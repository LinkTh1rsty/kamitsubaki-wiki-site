# KAMITSUBAKI Wiki

Unofficial multilingual fan encyclopedia. Use Node.js 22 and pnpm 11.1.1. Install with `pnpm install --frozen-lockfile`.

Read [development and contribution instructions](README.md) and [maintenance commands](README.md). [Reader guide](docs/manuals/site/start/en.md) and [contribution guide](docs/manuals/contribute/start/en.md) remain available. Production uses the main branch and `node scripts/release-build.mjs`; publishing requires explicit approval of a fixed candidate.
