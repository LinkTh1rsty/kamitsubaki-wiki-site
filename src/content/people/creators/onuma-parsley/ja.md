## 概要

**大沼パセリ**（Onuma Parsley）は、2017年より活動するコンポーザー兼シンガーソングライター。YouTubeで1000万回再生を突破した『エゴイスト』や『Corruption』で知られ、神椿では幸祜への楽曲提供や音楽的同位体（可不・狐子）の起用を精力的に行っています。

## 詳細な活動年表と個人的な嗜好

**年表（詳細）**

| 日付 | 出来事 |
| :--- | :--- |
| 2017-06-29 | 初作《夜明け前》を投稿 |
| 2018-02-20 | 《Corruption》を投稿し、ここから広く注目を集める |
| 2018-03-07 | 別の P 主・雨のち雨が歌唱する《アフタースクール》を投稿。のちに初音ミク歌唱の VOCALOID 版を公開 |
| 2018-04-24 | 自身の楽曲のセルフカバー動画の投稿を開始 |
| 2018-09-12 | 《エゴイスト》を投稿し、大きな反響を得る |
| 2019-06-20 | 《Billy》の投稿を最後に niconico への投稿を停止し、以降はすべて YouTube のみに投稿 |
| 2019-10-18 | 神椿の設立に伴い、加入をツイートで発表 |
| 2020-02 | 個人アルバム《ave》のリリースに伴い、P 主としての活動を休止 |
| 2020-09 | シングル《Latency》をリリースし、シンガーソングライターとして再び表舞台へ |
| 2021-05-08 | バーチャル歌姫[可不](/ja/database/isotopes/kafu)が歌唱する《水面下》を投稿 |
| 2023-05-10 | バーチャル歌姫[狐子](/ja/database/isotopes/coko)が歌唱する《ボニー&クライド》を投稿 |

**個人的な嗜好と界隈の雑談**

- **絵師との長期的な協働**：初期の曲絵は Piapro 上のさまざまな絵師の公開作品から取ることが多かったが、のちの曲絵は主に **ホンダソウイチ** が担当している。二人の仲は良く、互いを愛称で呼び合う；
- **同世代の P 主との交流**：P 主**案山子**と仲が良く、互いの曲を Remix し合い、ツイッターでも多くのやり取りがある；
- **個人アカウント**：**ぬまみたいな**（「沼のような」の意）というツイッターのサブアカウントで日常の細事を更新しており、その名義で YouTube にもカバーを 2 曲投稿している；
- **神椿内での供曲**：神椿では[幸祜](/ja/database/artists/solo/koko)へ頻繁に楽曲を提供している；
- **公言している嗜好**：BL が好きだとツイートしたことがある（{{spoiler::自称・腐男子}}）。好きな歌い手は WaMi、れい、宮下遊；
- **音楽歴**：子供の頃から歌うことが好きでカラオケによく通っていた。中学二年生で正式に楽器を学び始め、高校時代はバンドに参加しライブハウスでオリジナル曲を演奏したこともある。

> **スタイルのまとめ**：大沼パセリの歩みは神椿のクリエイターの中でもかなり特異である。「Piapro の絵＋柔らかな曲調」の初期から、大規模な削除とスタイルの再構築を経て「エレクトロ色の強い毒曲」へと定まり、さらに P 主活動の休止後に自作自演のシンガーソングライターへと転じた。この曲線そのものが、神椿の「クリエイターは変形し続けられる」というモデルの見本である。

## 投稿統計と創作規模

| 指標 | データ |
| :--- | :--- |
| **VOCALOID オリジナル曲の投稿数** | 記録時点で niconico 動画へ **26 曲** を投稿 |
| **殿堂入り** | **6 曲** が殿堂入り（10 万再生） |
| **伝説入り** | **1 曲** が伝説入り（100 万再生） |
| **使用した歌声ライブラリ** | 初音ミク、v flower、[可不](/ja/database/isotopes/kafu)、[狐子](/ja/database/isotopes/coko) |
| **プラットフォームの特徴** | YouTube の再生数は niconico より高いことが多く、最も知られる《エゴイスト》は YouTube で千万再生級に達している |

> **創作規模の意味**：投稿総数がさほど多くない前提で 6 曲の殿堂入りと 1 曲の伝説入りを達成していることは、作品の「的中率」が極めて高いことを示す。神椿の設立時に大沼パセリが初期メンバーの一人として数えられた重要な理由でもある。
