# Wiki → Folia

`PUBLIC_FOLIA_ORIGIN` 为空时关闭入口。允许任务预览域名或拟定正式音乐域名；不会默认把生产读者引向临时服务。

链接协议：`/listen?provider=qq&type=track|album&id=<14位mid>&lang=<Wiki语言>&wiki=<公开词条路径>`。登录凭据和用户ID不进入链接。独立标签打开，不自动播放；扫码后目标仍在，播放由用户按下。

`src/data/music-listen.json` 保存经核验的显式映射；已有标准QQ官方链接优先。2026-10-28 读取QQ公开《観測》专辑接口，核对花譜、2019-09-11、15首曲序与Wiki曲目表，映射该专辑及其15首专辑版本。QQ显示时长可能因尾音取整相差1秒。`source`可供人工复核，不根据标题自动绑定。后续增加映射需对照歌手、版本、专辑、曲序和官方页面，保留核验日期。

验收：探索入口、歌曲/专辑直达、匿名登录前后、明确播放、队列不重复、返回词条、错误/无映射、桌面/手机和旧影像入口。试播音频不能视为完整版成功。
