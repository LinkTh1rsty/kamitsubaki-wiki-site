# 脑暴方案 01：四位一体形态切换器 (Entity Morphing Switcher)

> **归档位置**：`docs/brainstorming/01-entity-morphing-switcher.md`  
> **议题性质**：实体建模 / 前端交互 / 设定哲学呈现  

---

## 1. 核心背景与痛点
神椿生态中存在极其特殊的“一个灵魂，多重存在形态”现象，这在传统百科中经常导致严重的归属混乱与用户迷失：
- 新人不知道“花谱”和“廻花”是不是同一个人；
- 不明白“可不”为什么声音像花谱，但又被称作“音乐同位体”；
- 在看《神椿市建设中。》动画或游戏时，不知道为什么里面有个叫“森先化歩”的女孩长得酷似花谱。

以花谱为例，其一人承载了四个维度的存在：
1. **虚拟歌姬魔女**：花谱 (KAF)
2. **现实创作二刀流**：廻花 (KAIKA)
3. **合成声学生态**：可不 (KAFU)
4. **神椿市都市住民**：森先化歩 (Morisaki Kaho)

---

## 2. 交互功能构想 (UI/UX)
在涉及此类人物的词条页面（无论用户从哪个入口点进来），顶部固定展示一个**「形态切换滑块 (Morphing Switcher)」**：

```text
┌────────────────────────────────────────────────────────────────────────────────────────┐
│ [ 当前观测形态 ]                                                                       │
│  ● 🌸 花谱 (歌姬)   ○ 🪞 廻花 (实体)   ○ ☕ 可不 (同位体)   ○ 🏙️ 森先化歩 (住民)        │
└────────────────────────────────────────────────────────────────────────────────────────┘
```

- **交互逻辑**：
  - 点击对应形态，当前页面平滑切换到该形态的专属档案，或者横向滑动展示其属性差异；
  - 页面主色调与视觉纹理实时动态变色：
    - 切换到【花谱】：经典蓝灰粉冷艳冷调；
    - 切换到【廻花】：纯白、实体素描手稿与民谣吉他质感；
    - 切换到【可不】：黄色警示线、机械代码与参数波形质感；
    - 切换到【森先化歩】：神椿市都市地图暗黑、复兴局公文印戳质感。

## 4. 技术落地思考
- 在 Astro Frontmatter 中定义 `morphingGroup: "kaf-family"` 与 `morphingRole: "virtual-witch"`；
- 页面组件读取该 Family 的全部兄弟词条，自动生成多形态快速跳转与元数据对照；
- 支持 SEO 独立收录，同时对读者形成直观的世界观认知冲击。
