# 脑暴方案 04：专栏生僻概念悬浮气泡卡片 (Lore Concept Hover Card)

> **归档位置**：`docs/brainstorming/04-lore-concept-hover-card.md`  
> **议题性质**：深度阅读体验 / 跨词条联动 / 降低理解门槛  

---

## 1. 核心背景与痛点
站内的深度特稿（如 50 亿 MBO 资本运作调研、廻花艺术哲学剖析、PNDR 商业闭环）具有极高的专业性和信息密度。但在行文中，往往充斥着神椿特有的黑话和官方术语：
> 例句：“在代代木 **「怪歌」** 现场，通过 **SINKA LIVE** 的虚实演剧机制，现场首次观测到了 **魔女特异点** 的 **普遍体** 剥离，从而降临为具备独立肉身的 **廻花**……”

对于新入坑或非硬核观测者，这种高频出现的专业术语会产生极大的挫败感和阅读阻碍。

---

## 2. 功能构想：黑客冷冽风悬浮气泡 (Tech-Style Hover Preview)

当文章中出现官方 80+ 专有名词、艺人代号或重要事件时，文本带有特定的微光下划线。鼠标悬停（移动端轻触）时，弹出一个精致的高科技卡片：

```text
                               ┌──────────────────────────────────────────────┐
                               │ ✦ SINKA LIVE [深化系统]                      │
...现场，通过 SINKA LIVE 的... │ -------------------------------------------- │
                ▲              │ 官方定义：神椿自研的虚实融合多幕剧虚拟演唱会 │
                │              │ 机制。通过实时动捕与虚幻引擎，打破传统单曲  │
                └──────────────│ 报幕模式，将整场演出组织为宏大剧情演剧。    │
                               │                                              │
                               │ [关联词条：SINKA LIVE 体系 ↗] [相关场次 ↗]   │
                               └──────────────────────────────────────────────┘
```

---

## 3. 悬浮卡片涵盖的实体类型
1. **世界观术语 (Glossary Terms)**：特异点、普遍体、战斗形态、共犯者、深化系统、Q市等；
2. **艺人与同位体 (Entity Card)**：悬停“花谱”显示其头像、代表作、身份定义；
3. **重要演出 (Live Events)**：悬停“不可解参狂”显示举办日期、地点（日本武道馆）、关键历史意义；
4. **商业与平台概念 (Biz Infrastructure)**：悬停“PNDR”显示其作为自研分发平台的功能概括。

---

## 4. 技术落地思考
- **Markdown 插件注入**：在 Astro 的 Rehype 管道中增加词条自动匹配插件，自动扫描并包裹带有 `data-wiki-term="sinka-live"` 的超轻量标记；
- **轻量前端 Popover**：使用原生 HTML `<dialog>` 或微型 Popover API，按需拉取内存预置的 80 个词条简释，无需发额外网络请求；
- **免跳出阅读**：读者不需要在读文章途中不断跳出页面去搜百科，大幅提升长文的停留时长与阅读完成率。
