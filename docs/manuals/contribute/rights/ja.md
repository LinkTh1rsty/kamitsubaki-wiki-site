## 事実と出典

公式告知、作品ページ、本人への取材など追跡可能な資料を優先します。タイトル、発行者、日付、アクセスできる URL を記録してください。二次的なまとめはその性質を示し、推測を公式の事実として記載しないでください。既存項目の正しい文章は残し、新しい情報を明確に追加します。出典は事実の根拠であり、記事と項目の明示的な関連ではありません。

## 画像と利用許可

画像の制作者、出所、利用する根拠を説明できる状態にしてください。ギャラリーのセットには共通の出典を設定でき、画像によって出典が異なる場合は個別に上書きします。項目の添付にも出典が必要です。アップロードによって著作権がサイトに移転したり、自由な転載許可が生まれたりするわけではありません。公開すべきでない個人情報や、出所を説明できない素材は投稿しないでください。迷う場合は[サイトのライセンス説明](/ja/license/)を読み、管理者に確認します。

## 言語版

簡体字中国語、日本語、英語を別々に維持します。項目の翻訳は安定 ID と構造上の同一性を共有し、台湾・香港の繁体字は簡体字から生成します。タイトルだけ訳して本文の大半が他言語のままなら完成した翻訳とはしません。記事は実際の本文言語で投稿し、別言語版にはその言語で確認した本文を用意します。年代記やギャラリーの関連は構造化データに従い、本文でキャラクターや日付に言及しても自動で記録は作られません。

## ライセンスの判断とフィールド例

### 既定のルール

- 別途表示がない限り、本サイトが許諾権限を有するオリジナル文章は [CC BY-NC-SA 4.0 国際](https://creativecommons.org/licenses/by-nc-sa/4.0/)で提供されます。
- 画像、ジャケット、歌詞、音声・映像、キャラクターデザイン、ロゴ、商標、その他の第三者素材は既定の文章ライセンスに含まれません。
- 他のサイトや著作者に由来する文章には元の条件が適用されます。ライセンス表示は転載許可の代わりにはならず、権利のない利用を正当化しません。
- プログラムコードとソフトウェアファイルはコンテンツ向け CC ライセンスの対象外です。
- 投稿画面では一律の CC 許諾を取得しません。他の投稿者の文章は、権利者が別途明示的に同意した場合、または記事に対応するライセンスが記録されている場合だけ 4.0 の対象になります。

## 記事の `license` フィールド

アーティスト、プロジェクト、ログ、楽曲、アルバムの YAML frontmatter で次の値を使用できます。

| `code` | 用途 |
| --- | --- |
| `CC-BY-NC-SA-4.0` | 本サイトが許諾できるオリジナル文章 |
| `CC-BY-NC-SA-3.0-CN` | 3.0 中国大陸版で提供される第三者の文章、その翻訳・翻案 |
| `rights-reserved` | 原権利者が権利を留保する内容 |
| `authorized-use` | 権利者からの特定の許諾範囲で使用する内容 |

未定義の `code` は `pnpm check` またはビルドで失敗します。

### 本サイトのオリジナル文章

```yaml
license:
  code: "CC-BY-NC-SA-4.0"
  attribution: "サイトの原著作者"
```

### 旧版 CC ライセンスで提供される第三者の文章

複製、翻訳、改稿、統合した場合は 3.0 CN を維持し、次の情報をすべて記録します。

```yaml
license:
  code: "CC-BY-NC-SA-3.0-CN"
  attribution: "原著作者と投稿者"
  sourceTitle: "元記事のタイトル"
  sourceUrl: "https://example.com/original-entry"
  modifications: "元記事を整理・改稿し、出典を補足。"
```

3.0 CN では `attribution`、`sourceTitle`、`sourceUrl`、`modifications` を記入し、審査者が元の許諾と変更を確認できるようにします。現在の基本 schema はライセンスコードを制限しますが、権利の人的審査に代わるものではありません。同じ文章を元にした翻訳にも各言語ファイルでこの表示が必要です。

### 権利留保と個別許諾

```yaml
license:
  code: "rights-reserved"
  attribution: "原著作者または権利者"
  sourceUrl: "https://example.com/original"
  note: "著作権は原著作者に帰属します。"
```

```yaml
license:
  code: "authorized-use"
  attribution: "権利者名"
  note: "権利者の許諾により、本サイトに限り使用します。"
```

`authorized-use` は実際に許諾を得た場合だけ使用します。`rights-reserved` と書くだけで複製権が得られるわけではありません。

## 画像とその他のメディア

詳細ページには共通のメディア除外表示があります。公式画像があるという理由だけで記事全体を `rights-reserved` にしないでください。

- 公式ページ、正規配信サービス、または許諾済み素材を優先します。
- 本文の出典と PR に、画像の出所と利用根拠を記録します。
- 出典不明、透かし除去、人工的な拡大、百科紹介の範囲を超える素材は追加しません。
- 歌詞全文は、転載を認める明確な出典または個別許諾がある場合だけ追加します。

## ギャラリー画像を一枚ずつ確認する

[画像を直接投稿](/ja/gallery/manage/photos/)する際は、人物や種類が未定でも**作者、確認できる出典、利用根拠**が各画像に必要です。バッチ共通の情報と異なる画像は個別に上書きします。公式公開素材には元ページの URL、許諾済み素材には許可の説明が必要です。既存の項目や記事で使われた画像は非公開の確認キューに入ります。サイト内で見つかっただけでは画像アーカイブに自動公開されません。

## レビュー時の確認

- オリジナル、許諾済み、または第三者ライセンスのどれか。
- 元のライセンスと同じバージョンを使用しているか。
- 元ページ、表示名、変更内容が揃っているか。
- 画像や歌詞が文章の CC ライセンスに含まれるように見えていないか。
- 3 言語で出典とライセンスの扱いが一致しているか。
- `pnpm test`、`pnpm check`、`pnpm build` が通るか。

## 投稿で選ぶ三つの利用根拠

| 選択肢 | 必要な情報 |
| --- | --- |
| 公式公開素材 | 原作者・公式クレジット、実際の公開元・作品名、原典ページ URL |
| 本人のオリジナル | 原作者本人であること、正確なクレジットと出典名。自分の原投稿も追加可能 |
| 許可済み | 原作者と原典、許可範囲・日付・確認可能な証拠 |

利用根拠の初期値は空欄です。出典の候補は許可の検証ではなく、公式公開も包括的な転載許可ではありません。作者や条件が異なる画像は個別に補足してください。不明な場合は非公開の下書きに保持して確認します。審査者は画像ごとに補足を求めて差し戻せます。
