> この手順は新しい投稿画面と記事エディターの公開に合わせて有効になります。管理者は対応するバックエンドの追加データベース移行を先に適用し、その後にフロントエンドと本ガイドを公開してください。非公開の一時保存が完了しても公開済みではなく、明示的な提出と審査が必要です。

## 新規作成と修正

[記事一覧](/ja/articles/)から[投稿ページ](/ja/articles/submit/)へ進みます。公開記事を直すときは記事リーダーの修正入口を使い、現在の公開版を確認します。本文のエディターは百科項目と共通ですが、**記事は GitHub PR を作成しません**。サイトはクラウド下書き、提案、公開版を別々の状態として表示します。

記事リーダーの修正入口は編集権限がある人だけに表示します。他の読者の「記事を投稿」は新しい記事を作成する入口で、閲覧中の記事を変更しません。

## 入力と保存

タイトル、本文言語、分類、本文を入力します。要約と関連項目は任意です。記事は単独でも公開でき、複数の項目に明示的に関連付けることもできます。関連を設定する場合は正しい安定 ID を選びます。本文の WikiLink や通常のリンクだけでは「関連記事」になりません。書式ツールやソース表示で執筆し、タイトル、段落、画像 URL、目次をプレビューします。「画像を挿入」で公開ギャラリーを検索するか、新しい画像を記事の非公開領域に保存します。代替テキスト・キャプション・作者・出典・利用根拠を記入します。既存の Markdown 画像構文も使用できます。

現在のブラウザーにも編集状態が残ります。ログイン後は入力が落ち着くとクラウドへ自動保存します。端末とクラウドの保存状態は別々に表示し、「下書きを保存」で手動同期もできます。オフラインの変更は端末に保持し、再接続後に再試行します。離れる前にクラウドの保存完了を確認し、別の端末では同じアカウントの Creator Center から続けてください。審査への提出前にタイトルと本文を完成させ、検査結果が指す箇所を修正します。

## 提出と審査

「審査に提出」を押し、受付表示を待ってから[クリエイターセンター](/ja/account/creator/)で記録を開きます。審査中・差し戻し中の新しい版は、既存の公開記事を上書きしません。管理者の承認後に本文言語の一覧へ反映されます。差し戻されたら意見を読んで修正し、再提出してください。版の競合が出た場合は新しい公開版と下書きを比較し、他の人の承認済み変更を無断で上書きしないでください。

## エディターでの具体例

項目に結び付けない研究記事なら、実際の執筆言語と分類を選び、題名・概要・本文を入力し、**関連項目は空欄**にします。二つの楽曲を扱う場合は、プロパティで両方の安定 ID を明示的に選択します。本文中の `[[WikiLink]]` は閲覧リンクであり、各楽曲の関連記事欄に記事を追加しません。下書きを保存して更新し、Creator Center でクラウド版を確認してから審査へ提出します。

本文エディターは百科項目と共通です。題名と分類はプロパティ、記事のソースモードは本文だけを扱います。長文は目次で移動し、プレビューで見出し・リンク・画像を確認します。公開ギャラリーの画像は既存の媒体を再利用します。新しい画像は非公開で一時保存し、サーバーの確認後に安定した参照を挿入します。承認と画像の公開同期が成功した後、公開記事から画像を読めるようになります。非公開のプレビューは本人と審査者だけが閲覧できます。`blob:` プレビュー URL を本文に保存しないでください。

## 公開記事の修正と競合

修正は承認済みの版を基準にします。審査中の変更は投稿者と審査者だけに見え、読者には以前の公開版が表示されます。先に別の修正が承認された場合は、新版と照合して再提出します。差し戻しは既存の記録で意見を読み、同じ文書を直してください。

## 公開前の確認

題名、本文、分類、概要、画像 URL と使用根拠、関連先 ID を確認します。受付から審査記録へ進み、新版を公開リーダーで読めるようになって初めて公開完了です。

## 二つの画面と画像公開の失敗

別の画面で同じ下書きが保存されると自動同期を停止し、端末とクラウドの内容を比較します。端末の内容を別の提案として保存するか、クラウド版を読み込めます。読み込む前に端末のバックアップを保持します。クリックの繰り返しで競合を回避しないでください。出典や許可が未完成の新画像は非公開の下書きに保持できますが、提出前に補足が必要です。画像の公開同期に失敗した場合、壊れた新画像を含む記事を公開版に切り替えません。審査記録を確認してから管理者が再試行します。

新しい画像を選ぶと非公開で一時保存します。本文に未挿入の画像情報と再試行の記録は現在の端末に保持します。別端末へ移る前に情報を補足して本文に挿入し、クラウド保存を確認してください。公開ギャラリーの画像は代替テキストとキャプションだけを変更し、審査済みの出典と利用根拠を保持します。
