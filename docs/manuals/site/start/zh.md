## 网站地图

首页保留精选预览。**百科**收录人物、团体、项目等词条；`02. RHYTHM 音乐作品` 收录歌曲和专辑。点击分类进入完整目录，不必在首页一次展开所有记录。**文章专栏**是经审核的独立文章；**探索**连接纪元时间轴、设定图库、关联网络和世界观导览；**LABs · Beta** 放置游戏和实验体验。投稿入口在**参与共建**，帮助内容在 **DOCUMENTS**。

## 找到目标

知道名字时使用站内搜索，也可从百科分类逐层查找。先区分“词条”和“文章”：词条是资料档案，文章可以是研究、专访或观点；文章与词条的关联由投稿时明确选择，不会因为正文提及某个名字而自动建立。

## 语言与状态

页面提供简中、日文、英文及由简中生成的繁体界面。某篇文章只会在其已公开的内容语言下出现；切换界面语言不会凭空生成文章译文。词条占位表示资料仍待补完，不等于实体不存在。遇到错误或缺漏，可以到[参与共建](/zh/contribute/)选择任务。

## 按目的选择入口

| 目标 | 从哪里进入 | 会看到什么 |
| --- | --- | --- |
| 查一个人物、团体或项目 | 首页百科 → 对应分类，或使用站内搜索 | 有稳定 ID 的百科词条及其关联档案。 |
| 找歌曲或专辑 | `02. RHYTHM 音乐作品` → 音乐目录 | 歌曲与发行作品的独立目录。 |
| 阅读研究、报道或观点 | 文章专栏 | 当前内容语言下已审核的文章。 |
| 按日期或角色找资料 | 探索 → 时间轴／图库 | 事件与设定图片，遵守各自的审核状态。 |
| 做纠错或投稿 | 参与共建 | 词条、文章、图库三条任务及进度入口。 |

搜索不到时先检查译名、原文名、别名和语言，再试上级分类。首页卡片是精选预览，不是完整数据库；目录里的“继续展开”按批次显示更多项目。公开页面可能有占位条目，表示该实体位置已确认但正文仍待完善。遇到占位可以从其阅读页进入编辑，也可以在贡献中心选择新建或补完。

## 区分界面语言与内容语言

切换站点语言会改变导航和可用的对应内容，但不会自动翻译一篇未提供译文的文章。简体中文、日文、英文词条各有维护源，繁体版本从简体中文生成。引用或纠错时记录你实际看到的语言和页面地址，这有助于维护者定位源稿。

## 使用文档站

文档按使用网站、编辑与投稿、开发与维护分组。桌面从左侧选择章节，用页内目录定位段落；手机展开“文档导航”和“本页目录”。每页的搜索会检索当前语言的正式章节，支持标题与正文关键词。旧版归档不在搜索结果中。

切换语言会留在同一章节。关闭搜索后可以继续原处阅读；网络不可用时仍可浏览已打开的正文与章节链接。
