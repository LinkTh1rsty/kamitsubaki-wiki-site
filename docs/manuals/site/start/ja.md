## サイトの構成

トップページは全件ではなく、主な項目を紹介します。**百科**には人物、グループ、企画などの項目があり、**02. RHYTHM** には楽曲とリリースがあります。分類から全件の一覧へ進み、多い項目は少しずつ展開できます。**記事**は審査済みの独立した文章です。**探索**には年代記、設定資料ギャラリー、関連ネットワーク、世界観ガイドがあります。ゲームなどの試験的な機能は **LABs · Beta** にまとめています。投稿は**貢献する**、説明は **DOCUMENTS** から開けます。

## 目的の資料を探す

名前で検索するか、百科の階層をたどってください。百科の項目は資料としての記録で、記事には研究、インタビュー、意見などがあります。記事と項目の関連は投稿時に対象を明示して作ります。本文に名前を書くだけでは関連付けされません。

## 言語と未完成の項目

画面は簡体字中国語、日本語、英語、および簡体字から生成した繁体字に対応します。記事は公開済みの本文言語でのみ表示され、画面の言語切替では翻訳されません。「仮項目」は情報の追加を待っている状態です。誤りや不足は[投稿ページ](/ja/contribute/)から知らせてください。

## 目的から入口を選ぶ

| 目的 | 入口 | 表示されるもの |
| --- | --- | --- |
| 人物・ユニット・企画を探す | ホームの百科 → 分類、または検索 | 正規の百科項目と関連資料。 |
| 楽曲・リリースを探す | `02. RHYTHM` → 音楽一覧 | 楽曲とリリースの別々の一覧。 |
| 研究・論考を読む | 記事欄 | 現在の本文言語で審査済みの記事。 |
| 日付・キャラクターから探す | 探索 → 年代記・ギャラリー | 出来事や承認済みの画像。 |
| 修正・投稿する | 貢献 | 百科・記事・ギャラリーの三つの作業と進捗。 |

見つからない場合は訳名・原語名・別名・言語・上位分類を確認します。ホームのカードは抜粋であり、一覧は必要に応じて分割表示します。仮項目は実体の位置が確認され、本文の充実を待っている状態です。項目から修正を提案できます。

## UI 言語と本文言語

UI 言語を切り替えても、訳文のない記事が自動翻訳されるわけではありません。簡体字中国語・日本語・英語の項目はそれぞれ原文を維持し、繁体字版は簡体字版から生成されます。誤りの報告には実際の言語と URL を添えてください。

## ドキュメントを使う

サイト利用、編集・投稿、開発・保守の三つに分かれています。デスクトップでは左側から章を選び、ページ内の目次で段落に移動します。スマートフォンではナビゲーションと目次を展開します。各ページの検索は現在の言語の正式な章を対象に、タイトルと本文を調べます。過去のアーカイブは検索対象外です。

言語を切り替えても同じ章に移動します。検索を閉じると読書を続けられ、通信できない場合でも開いた本文と章リンクを利用できます。
