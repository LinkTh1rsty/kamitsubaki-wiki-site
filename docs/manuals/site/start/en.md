## Map of the site

The home page shows a selection rather than every record. **Encyclopedia** holds people, groups, projects, and other entries; **02. RHYTHM** covers tracks and releases. Follow a category to see the full directory and reveal more entries in batches. **Articles** contains reviewed, independent writing. **Explore** brings together the chronicle, reference gallery, relationship network, and world guide. **LABs · Beta** contains games and experiments. Use **Contribute** to submit work and **DOCUMENTS** for instructions.

## Find a subject

Search by name or browse the encyclopedia hierarchy. An entry is a reference record; an article may present research, an interview, or an opinion. An article is associated with an entry only when the contributor explicitly selects that relationship. Mentioning a name in the article body does not create an association.

## Languages and incomplete records

The interface supports Simplified Chinese, Japanese, English, and Traditional Chinese generated from Simplified Chinese. An article appears only in its published content language; changing the interface language does not translate it. A placeholder entry means that its information still needs work, not that the subject is absent. Use [Contribute](/en/contribute/) to report or correct a gap.

## Choose a route by task

| Goal | Start here | Result |
| --- | --- | --- |
| Find a person, unit, or project | Home encyclopedia → category, or site search | A canonical entry and related records. |
| Find a track or release | `02. RHYTHM` → music directory | Separate track and release catalogs. |
| Read research or commentary | Articles | Reviewed articles in the current content language. |
| Browse by date or character | Explore → chronicle or gallery | Events or approved reference images. |
| Correct or submit material | Contribute | Entry, article, and gallery tasks with progress links. |

If search misses a record, try translated and original names, aliases, another language, and the parent category. Home cards preview selected content rather than the whole database; long directories reveal further items in batches. A placeholder entry marks a known catalog position awaiting a fuller body. Open it to propose a correction or addition.

## Interface language and content language

Changing interface language changes navigation and available content, but it does not translate an article that has no supplied translation. Simplified Chinese, Japanese, and English entries have maintained sources; Traditional Chinese is generated from Simplified Chinese. Include the exact language and URL when reporting an error so a maintainer can locate the source.

## Use the documentation site

Documentation is grouped into using the site, editing and contributing, and development and maintenance. On desktop, choose a chapter in the left sidebar and use the page outline to jump to a section. On phones, expand the chapter navigation and page outline. Search on any page covers titles and prose in published chapters of the current language. Historical archives are excluded.

Switching languages keeps you in the same chapter. Close search to continue reading. An already opened body and its chapter links remain usable when the network is unavailable.
