Use Node.js 22 and pnpm 11.1.1; install with pnpm install --frozen-lockfile. Each task owns its branch, worktree, ports and test data, starting from current main and integrating updates. Candidate environments explicitly use local API origins rather than production-connected development scripts. Before submission, run tests, Astro checks, shared-component and documentation checks, the build and link audits. A successful build does not prove login, contribution or gallery state transitions.
