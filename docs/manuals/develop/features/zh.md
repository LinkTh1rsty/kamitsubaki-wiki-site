## 变更前准备

先复现问题，记录页面 URL、语言、视口、主题和数据来源。用本任务的隔离来源与数据验证列表、详情、操作和刷新后读回，不用生产账号或记录测试。

## 活动中心

入口为 `/{locale}/events/`，默认观测者企划；`?source=official` 切换官方。旧活动入口保持兼容。来源、月份、视图、筛选和日期保存在 URL，刷新或分享后应可恢复。

日历使用 FullCalendar 标准插件；地区选择复用 Tom Select，浮层用 Floating UI，海报查看用 PhotoSwipe。检查跨日事件、更多弹层、无内容和失败状态。全天日期不转换时区，未知结束不补默认时长，无确定日期的活动不生成定位或单活动日历文件。

公开活动读取 `/api/activity-center`。桌面默认月历，手机默认列表；手机筛选沿用同一表单状态。海报完整显示，缺图时仍可阅读文字和打开详情。分享文案不携带统计入口参数。

## 观测面板与公告

BaseLayout 挂载一个 ObserverDashboard，包含总览、公告、AI、工具。发电入口独立。企划与官方分别展示，不把曝光或点击统计解释为报名结果。

公告位于 `src/content/announcements`，沿用 translationKey、pinned、autoOpen、order。`reminderVersion` 仅在重要修订确实需要重新提醒时递增；普通修字不递增。跨语言切换不应重复提醒。

AI 在首次选中时按需初始化。切换区域或关闭面板保留草稿与请求；账号切换应取消旧请求并清空旧会话。检查 Esc、背景隔离、关闭后焦点恢复和无 JavaScript 的普通入口。

## 文章阅读器

`articleReaderPresentation.mjs` 由客户端与 Pages Function 共用，保持服务端首屏与后续刷新一致。author 保留原署名，头像来自已有账号映射；缺失或不安全的头像用现有图标，不按昵称猜绑定。

刷新失败保留标题和正文，允许重试；不重复插入目录或绑定点击事件。关联词条由明确的关联 ID 决定，正文链接不等于业务关联。

## 编辑器与发言块

词条和文章共用 `prototypes/novel-editor`。保留插入菜单、属性、源码和预览之间的往返。发言者在发言编辑处维护，头像、颜色和词条绑定为可选项，与文档作者分开。

快速导入先展示预览，未标注发言者的段落保持普通正文。插入后可撤销，不为可撤销操作增加重复确认。保留原文、来源和未知写法；操作说明见[语法参考](/zh/docs/contribute/syntax/)。

## 结果与限制

检查加载、空状态、失败、恢复以及手机焦点。测试文件可从对应功能名查找，完整门禁见[检查与发布](/zh/docs/develop/operations/)。本机模拟不证明真实供应商、生产权限或发布成功。
