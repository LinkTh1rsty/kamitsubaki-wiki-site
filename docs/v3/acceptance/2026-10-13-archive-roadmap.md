## 数据口径

按 V3 统一实体 ID 去重，本机共有 1,836 个实体：1,557 首歌曲、158 项发行、12 项现场活动及其他人物、团体、软件、世界观和项目实体；时间轴另有 518 条事件。歌曲中 153 首填写了非空结构化 `credits`，活动中尚无非空结构化 `setlist`。旧资料正文可能含有这些信息，不能把字段空白理解成完全没有相关资料，也不能直接把旧目录文件数当作 V3 有效词条数。

资料看板的中文口径为 6,488 个待补结构字段，平均覆盖率 42%；1,404 首歌曲待补制作名单，8 项演出待补曲目。展览和一般活动不被分配演出曲目任务。所有实体的结构化 `sources` 都待补，这并不表示正文没有引用。翻译回退另列，繁体自动转换不算缺少独立译文，译文缺项不扣元数据分数。

## 本轮可复查行为

- `/{locale}/explore/relations/?from=kaf&to=rim`：根据显式关联找到两步路径“花谱 → 不可解弐 → 理芽”，每一步保留原始方向与依据入口。名称、别名、ID 可选择端点；重名不猜测。可交换端点，继续以任一节点探索，浏览器前后退会恢复地址中的状态。默认不经时间轴事件连接，可显式勾选包含事件。
- `/{locale}/contribute/missing/?type=work-track&field=credits`：展示歌曲制作名单缺项。搜索同时包含词条名称、别名、ID 和明确关联的艺人/创作者名称，支持类型、缺项及排序组合。每次展示 24 条，可继续展开；清除条件与浏览器历史恢复已检查。
- 编辑入口使用实际内容源文件和回退语言，繁体页面跳到简体源文；缺少可靠路径时不生成编辑链接。补充仍走现有审核流程。
- 简体、台湾繁体、香港繁体、日文、英文均生成对应页面与文案。无 JavaScript 时看板仍显示 24 条可阅读词条。
- 增加图算法、端点消歧、字段规则及真实脚本 DOM 交互测试；修复四处旧测试的 Windows 文件 URL 转路径和一处 BOM/CRLF 前言解析问题。

维护方法见 [功能数据与关联维护](../feature-maintenance.md)、[探索使用说明](../../manuals/site/explore/zh.md)与[词条补充说明](../../manuals/contribute/entry/zh.md)。
