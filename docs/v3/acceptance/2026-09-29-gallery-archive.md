# V3 图片档案本地验收（2026-09-29）

本记录对应当前前后端工作树及本机演示，不代表线上发布。演示账号、图片和审核数据由本地脚本临时生成；重启演示服务会清空这些数据。既有站点内容图片只进入待核对队列，不能把扫描结果视为已获授权的公开图库内容。

## 实现范围

- 公开图库以已公开照片为默认视图；支持待分类、受控图片类型、人物／团体、标签和设定组筛选。图片可在原有查看器前后浏览，关闭后恢复筛选及浏览位置。旧设定组接口、`character` 字段与图片深链接保留兼容。
- 上传工作台区分直接批量上传照片与创建设定组。直接上传不要求人物、类型或设定组；每张照片须有作者、出处及使用依据。批次资料可被单张照片覆盖。页面区分本机草稿、私有暂存、审核中及公开状态。
- 已登录投稿者可为单张或多张公开照片提交分类建议；人物／团体、类型、标签和可选设定组均经审核后更新。审核期间保留原公开版本。后台将照片、分类建议和旧图候选放在同一图库审核工作台，提供逐图来源、变更与退回理由。
- 数据迁移扩充现有图片实体，设定组改为可选；新增图片类型、多对象关联、标签索引和版本校验。独立照片通过后不再自动生成单图设定组；公开列表只返回已公开图片，私有暂存不可通过公开路径读取。
- 内容扫描根据规范化地址和文件内容去重，并记录出现页面。当前清单含 **1000** 张唯一图片、**8680** 处页面引用，文件缺失数为 **0**；重复导入只补充引用，不覆盖已审核标签。缺少逐图来源或使用依据时，旧图留在待核对队列。
- 中、日、英投稿文档已说明两条上传路线、分类建议、权利资料和审核状态；繁体中文由既有生成流程同步。
