# V3 三本说明书整理与验收记录

## 范围与来源

站内文档中心使用 `docs/manuals/` 的网站、贡献、开发三本说明书，分别维护简中、日文、英文源稿；台湾和香港繁体由简中生成。工作区 `../docs/` 为同步镜像。旧站内文档和贡献中心原稿保存在仓库外 `../_untracked-archive/`，不再作为公开现行规则。

“内容与格式”及“语法与属性”保留原文主体和示例，作为贡献分册的完整章节。旧贡献、图片、许可、分类、文章、图库、Reader、组件和发布文档中的有效步骤按任务重组。旧许可示例中的个人署名改成通用作者名；公开章节不放密钥、私有配置值、本机绝对路径或内部调试地址。原版权文档关于 3.0 CN 字段“schema 必然报错”的说法与当前 schema 不符，已改为明确的编辑审核要求。

## 本地验收

- `pnpm i18n:generate`：五种站点语言的章节已生成。
- `node scripts/check-docs.mjs`：206 份 Markdown 的本地链接可解析。
- `node scripts/sync-docs.mjs --check`：主站与工作区镜像一致。
- `pnpm check`：0 错误、0 警告；85 条现有提示。
- 针对性文档、繁体、贡献链路和 V3 契约测试：56 项通过。
- `pnpm build`：构建成功；长文“内容与格式”“语法与属性”五种语言页面生成，旧地址生成跳转页。
- `node scripts/v3/check-built-links.mjs`：无缺失页面或退役地址引用；输出另有 205 条无法静态解析的引用，未把它们记为缺失链接。
- 内置浏览器：文档中心列出三本分册和完整贡献章节；搜索正文 `750 KB` 能定位词条附件说明，摘要不显示 Markdown 标记；“内容与格式”由共享 Reader 显示 33 项目录，章节锚点可跳转；窄屏目录默认收起并可展开，桌面保留固定目录；旧贡献指南入口跳到新章节；页脚显示 `DOCUMENTS`。

## 验收边界

本次只修改文档、导航与阅读接入，没有向真实服务投稿、上传或审核，也没有自动发布前端。上述结果证明本地文档阅读和构建，不代表线上站点已经更新。真实登录后从投稿入口返回指南的完整路径仍需在发布前预览环境复核。
