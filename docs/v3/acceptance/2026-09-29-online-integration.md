# V3 图片档案：线上数据联调（2026-09-29）

这份记录区分已更新的公开服务、连接正式接口的本地前端、模拟后台和仍待验证的登录审核流程。它不是前台上线或投稿审核完成的证明。

## 已更新的公开服务

- 正式公开接口 `api.kamitsubaki.wiki` 已更新，前台网站仍未发布本轮改动。
- 服务端 281 项测试和 27 篇文档链接检查通过；发布前的打包检查通过。

## 本地前端连接正式公开接口

- 使用 `pnpm dev:online` 的本地前台 `http://127.0.0.1:4322/zh/gallery/`。此模式使用正式 API，不启用示例身份；前台代码仍只在本机。
- 之前用于联调的 3 张测试图片及其文件已删除。本次从现有站点内容与图片文件整理了 1009 张唯一图片：1000 张被词条正文引用（8680 处引用），另有 9 张尚未关联词条的站内素材。投稿者头像及相同内容的重复文件没有建新照片。
- 这 1009 张按维护者本轮明确授权作为“站内既有图片”收录，正式图库中均为公开状态，待导入队列为 0。每张保留站内页面或原文件链接，并标记原图作者、出处和使用依据待补；这不表示已有权利核验。新增投稿仍按常规规则要求填写作者、出处与使用依据。
- 正式图库复核：1009 张公开照片、1009 个唯一内容哈希、1297 条人物／团体关联、1009 条导入审计、0 张缺少图片地址。
- 本地前台修复筛选、照片／设定组切换时的空白闪动：请求期间保留原网格和控制，结果到达后一次更新；进入设定组详情前先取数据。连接正式接口复查后，页面显示 1009 张，彩色原图和查看器均可打开，站内来源与待补资料说明可见。
- 照片逐图退回后，创作者中心的修改入口会恢复被退回的私有照片与意见到新草稿；此链路已通过服务端隔离测试，但正式账号的操作仍待验证。
- 前台 437 项测试通过，类型检查为 0 错误、0 警告；完整构建产出 9684 个页面。构建前的内容校验仍有既有提示，不能据此声称内容无警告。前台 222 篇文档链接检查通过。

## 仍未完成的真实验收

- 正式后台受 Cloudflare Access 保护。公开接口与正式图库记录已核对；管理员页面的实际登录、来源补全按钮与记录筛选仍未在已登录浏览器中验收。本地后台预览含虚构记录，只证明页面布局和按钮层级。
- 真实投稿者的私有上传、批次暂存、分类建议、逐图退回、版本冲突、审核通过与公开同步尚未在正式账号下走通。待核对队列数量不等于审核通过或公开数量。
- 前台尚未发布。发布后仍需核对正式页面、公开接口与图片状态，并完成五语言、深浅主题、桌面与窄屏、键盘与触摸的最终验收。

本地预览入口：`http://127.0.0.1:4322/zh/gallery/`（正式公开数据）、`http://127.0.0.1:8789/admin/review?type=gallery-photo`（虚构后台样本）。
