# V3 分类目录实施与验收

分类依据：`../category-optimization/classification-detailed-map.md`。导航树的唯一实现数据为 `src/data/classification-map.json`，首页和数据库复用同一组件。

## 归属规则

- 七个一级分类保留文档顺序；个人艺人仅文档列出的 12 项，核心词曲创作者 11 项、策划监督 4 项。禁止根据 vocalist / composer 等角色自动扩充这些目录。
- 演艺组合仅文档列出的六组。先选组合，再显示组合阅读入口和成员列表。心世纪的美古途、氷夏至、夕凪機以及罪十罚的硝子宮、御莉姫、佳鏡院不得进入个人艺人目录。成员显示名称沿用既有元数据；没有擅自按分类图中的译名重写正文。
- 少女革命计划成员的阅读 URL 为 `/database/artists/groups/{unit}/members/{id}/`。花谱等文档明确单列的个人艺人保留个人入口，同时可在所属组合下浏览。
- 唱片编目保留专辑、EP、单曲、原声、现场录音五类；企划保留神椿市下的动画、游戏、文学、ARG 分支；组织四层分组、术语四分组、虚构住民均逐层展开。
- 地图未点名的旧实体继续通过跨分类检索访问，不以职业标签擅自插入地图名单。计数取实际资料，未照抄文档的历史统计快照。

### 留存的正文冲突

旧版美古途等成员正文中的组合名称与用户指定分类地图不一致。本次导航与阅读器路径严格按地图安排；为遵守不改动旧正文的要求，原文保持不变，待新的资料整理任务统一核对，不能将本次目录调整视为原文事实已经校正。

## 占位边界

`classification-placeholders.json` 记录本次建立的 89 个占位实体。只建立标题和必要类型字段，正文仅说明待补全。未恢复此前撤回的资料库导入正文，未补造日期、作者或履历；中日英均有占位提示，繁体由原生成流程处理。占位阅读器明确显示状态并设为 noindex。

地图标注需核实的 ALLT / PHASE / QA 保留待核实提示。市濑留莉不擅自合并为其他相似姓名实体。地图中作品示例与现有标题、版本、媒体类型有差异，新增作品占位标为待核实；后续补资料时逐项确认，不将地图的说明性描述直接当成已核实事实。

## 交互与动效

- 保留一级选择器与嵌套子选择器逻辑，使用现有 SelectionGroup 滑块。取消整块内容左右滑入的附加动画。
- 每组选择器采用等宽网格、相同行高（桌面 44px，手机子目录 42px、一级目录 48px）；长名称换行，不用 flex 内容宽度改变方块大小。六组合桌面为 3 × 2，手机为 2 × 3。
- 艺人封面固定正方形；首页保留双背景图层及原背景切换机制。
- 复用旧版 reveal-up 入场以及 artist-collapsible 高度展开、逐条淡入位移动画，修复新列表 transition 覆盖原动画的问题。
- 首批 12 条，之后每次只展开 12 条，可收起到首批。未展开项保留在 template 中。
- 深层目录可以通过 `?section=` 直达；选择器支持方向键、Home、End。

## 验证

- `tests/classification-map.test.mjs`：地图引用完整、七类及细分结构、个人 12 项、少女革命成员归属和 URL、占位日期校验，共 4 项。
- `scripts/validate-content.mjs`：原有 5259 份正文哈希保留。时间轴日英待译警告仍然保留，不属于本次分类修复的已完成内容。
- 内置浏览器：1280 桌面与 390 手机检查；组合切换、深层目录直达、歌曲 12 → 24 → 12、占位入口分别验证。最终预览以 4360 构建产物为准。

## 首页标题回归

首页沿用原有 `01. DATABASE / 观测对象一览` 编号小标题，与 `02. RHYTHM / 音乐作品` 使用同样的字号、字距和双栏章节布局。移除新增的大号宣传标题，分类标题恢复原有 16px 衬线风格。仅首页适配，不改百科独立页面标题。

## 条目悬停回归

对照旧版 `ArtistDatabase.astro` 与现有 `SongsSection.astro`：恢复整行 16px 横向推进（400ms）、封面在固定正方形裁切框内轻微放大与提亮（500ms）、标题/副标题提亮（300ms）、右箭头从左侧淡入（300ms）。删除新条目的斜向箭头微移；修复局部 padding 覆盖 `.list-row:hover` 的问题。键盘聚焦有同样的提示，减少动态效果偏好下不移动或缩放。首页原有双层艺人背景继续由 pointerover / focusin 驱动。

内置浏览器对照歌曲与理芽条目，验证真实指针进入后的封面、文字、箭头及艺人背景。完整构建记录：`/tmp/v3-record-hover-build.log`。
