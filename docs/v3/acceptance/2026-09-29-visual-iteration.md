# V3 视觉与交互复查（2026-09-29）

这是本地工作树的复查记录，不是设计验收、真实投稿验收或线上发布证明。旧版点状时间轴已被用户否决；本轮以用户确认的横向轨道和事件块为准。前台与服务端均未部署。

## 本轮调整

- 时间轴保留横向轨道与片段。日期刻度上的播放头可连续拖动，轨道空白处可拖动平移，总览窗口可拖动和键盘平移；持续事件与聚合片段按真实时间跨度绘制宽度，密集片段随缩放展开，悬停或聚焦可预览，点击固定详情。新增可直接切换的站点时间轴视图，每条已公开公告对应一个独立事件块，详情可进入公告阅读器。
- 公告改成可浏览历史、按篇阅读、前后篇切换的档案页；从首页公告进入历史，返回时可关联站点时间轴。修正不同公告内同名标题可能产生的重复锚点。
- 我的空间重排为工作、收藏和账户三级；首屏显示身份与服务状态、继续投稿入口和下一步。创作者中心以待处理及草稿优先，再按每份记录呈现类型、状态、反馈和下一步操作。栏目切换保留当前位置。
- 探索页、投稿选择页、文档首页与 404 使用统一页面骨架。文档的站内编辑和 GitHub 快捷入口现在可直接滚动到相应步骤；手写锚点要使用渲染后的 `wiki-content-` 前缀。
- 图库默认照片视图，桌面把视图、角色和搜索并排，手机默认收起角色与形态筛选，让照片进入首屏；已选角色留在筛选按钮上。缩略图标题位于图片下方，不遮住图片。服务不可用时隐藏空白筛选框和网格，显示明确的重试入口。筛选与设定组返回恢复键盘焦点。
- 后台页面使用同一导航、令牌、页头及状态规范；本地虚构数据预览检查了 AI 控制台、运行与审计页。
- 联系面板打开时解除 `inert`，关闭时恢复并把焦点送回入口；面板和社群链接补充明确的可访问名称。
- 时间轴切换、公告档案、视图与投稿等操作文案纳入中日英源文案，繁体页面使用现有转换流程。浏览器已确认繁体站点时间轴与公告入口。

## 本地浏览观察

使用 Codex 内置浏览器在本机预览，未操作正式 Chrome。桌面检查了我的空间、创作者中心、探索、图库失败状态、时间轴、公告档案、文档首页与指南、404；手机宽度 390 px 检查了时间轴、公告、账号和指南。时间轴拖动播放头会连续改变日期，拖动空轨道会平移时间窗口，键盘聚焦片段会预览，选择聚合片段可逐条访问事件。站点轨在较高缩放下展示 9 条独立公告片段。文档快捷入口已在浏览器确认滚动到正文对应步骤。

站点时间轴切换后显示 9 条公告各自的事件块；浏览器里核对了事件进入对应公告、公告返回同一事件，以及手机和桌面宽度下的入口。后台 `preview:ai-core-admin` 使用虚构数据且不连接正式服务；只用于检查布局与操作层级。图库公开接口在普通本地浏览环境中不可达；另启隔离的本地样本接口，检查桌面和手机照片首屏、角色筛选、设定组切换、看图前后浏览、来源展开与关闭返回。样本图片不能证明真实公开图片可见。
