## 已检查的页面与交互

- 首页与公告：旧 V2.4.0 公告不会在首次进入 V3 时自动遮挡首页，仍可从公告入口打开。
- 账号与投稿：游客首页说明本机草稿与登录后的能力；创作者中心显示分组和下一步入口。词条、文章、设定图库、时间轴各有投稿路线。
- 全局菜单与 404：联系面板展开后不再引起语言和主题控件移动；菜单与工具互斥，可用 Esc 关闭并恢复焦点。404 优先提供搜索、探索、文档和首页入口。
- 图库：用明确标识的本地替身图片检查照片网格、角色筛选、设定组详情、前后看图、说明与来源展开，以及返回原筛选和滚动位置；手机看图完整适配。替身数据不能证明真实公开图片可见。
- 时间轴：展示 518 条事件；桌面侧栏显示选中详情，手机选择密集标记后可看到详情。事件聚合中可逐条选择、查看来源与修订入口。
- 时间轴投稿：游客草稿可在本机保存和恢复，预览与登录返回入口可用；日期精度切换会提示相应格式。手机、平板和桌面布局已抽查。
- 文档：按任务区分站内编辑与 GitHub 投稿，章节、页内导航和窄屏阅读可用。简中、台港繁中、日文、英文的图库、文档和时间轴投稿页均在构建产物中；五语投稿标题已抽查。
