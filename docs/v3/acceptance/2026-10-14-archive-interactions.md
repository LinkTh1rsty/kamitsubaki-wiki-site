# 2026-10-14 交互地图、扫描与实体导航

本批沿 [roadmap](../fan-archive-roadmap.md) 继续完成 F02、F06、F13、F19、U04、U07 和 Q01 的可实施内容。使用说明见 [Fan Archive 扩展功能](../features/archive-expansion.md)。本批属于 PR 候选增量，尚未发布。

## 制作范围

- F02：按读者选择加载 Leaflet 交互地图，使用已核对坐标；缩放控件保留全站图标，地点支持键盘选择。背景地图署名可见，读取失败保留标记与地点列表。筛选后销毁旧地图；巡礼连线表示选定地点顺序。
- F06：视觉列表纳入已记录封面和形态，复用 PhotoSwipe 放大、浏览与资料面板。显式视觉使用日期与未知初出分开，发行和出道日期不替代初出日期；年份筛选排除未知日期。
- F19：浏览器原生识别与 ZXing 软件后备解码，识别格式限定为零售条码；校验码通过后才匹配目录。停止、成功、离页、后台以及启动期间取消均释放自身相机流。
- U04：人物、歌曲、专辑和演出提供真实关联数量与直接档案链接。作品／演出按实体身份去重，署名／曲目按条目统计。公开图片数量由图库公开结果提供，失败保持未知。
- U07：图片查看控件跟随五种站点语言，保留图标与可选择资料；减少动画偏好生效。详情关闭、Escape 和浏览器返回清除内嵌播放器，并恢复操作入口焦点。浏览器恢复保存页面时重新挂载地图与房间参与刷新。
- Q01：整站链接检查确认旧日志日文路径的等价字符差异会导致五种语言返回 404；列表与静态路由统一字符形式，并保留编辑入口的原始文件路径。补上跨语言去重和规范路径回归测试。

Leaflet、ZXing 与既有 PhotoSwipe 的许可证随站点提供于 `/third-party-notices.txt`。Leaflet 1.9.4、ZXing Browser 0.1.5 和 Core 0.21.3 固定版本，复用既有 PhotoSwipe 5.4.4；保持现有构建环境兼容。许可记录随代码提交。地图背景不预取、不批量下载，后台没有新增外部自动采集。

- F13：复用正文已声明的媒体短代码与现有安全解析器，补上音乐详情和 Radio 的实际播放索引。共有 809 个档案、其中 806 首歌曲具备已记录的可嵌入播放器；不把普通相关外链、代码示例或注释误当成当前作品的播放来源。

## 数据边界

本批没有增加推测性事实。新增固定快照 `fd08cbab0467f0d0cf51427cbc578b766c22ebb3cc75f1ed87429865aa76bf74` 保留实际播放器链接，先前固定快照不变。当前仍为 1 个核对坐标、1 份有日期的视觉记录、5 个实体版次／物品及 0 个已记录条码；已有封面可显示为未知视觉日期。未知条码不创建或匹配假产品。软件识别用合成条码图片与视频流检查，地图浏览用本地背景图片检查，这些不能计为真实硬件相机或真实地图网络验收。

## 检查

最终自动测试共 847 项通过，覆盖实际正文播放器索引、条码解码与相机清理、实体计数、视觉日期、语言控件及日志路径回归。类型检查 768 个文件，0 错误、0 警告、103 提示；图标审计通过 222 个静态引用与 57 个已选择图标。贡献操作链接、歌词时间戳、数据契约与固定快照校验通过。公共字体许可证与游戏样式版本校验补上换行一致性处理，字体二进制仍严格逐字节比较。相邻服务仓库缺失，跨仓库检查范围明确保留。

在线配置整站构建生成 12,314 页。五种语言 × 17 个工作区逐页检查、375／600／820／1440／1920 五种宽度、查询分享与返回、年度对比零值、条码校验及闰日查询通过。地图键盘选择、背景失败、筛选销毁和缓存页面恢复、大图语言与文字选择、焦点恢复、详情 Escape／返回时移除播放器，以及合成视频流中的实际软件解码通过，无页面脚本异常。

账号头像／菜单／主站安全入口与图库大图以本地服务资料复查通过，手机和桌面深色页面没有横向溢出。整站链接检查覆盖 14,996 条内部路径，缺失链接、旧分类路径和未解析引用均为零。资源审核通过 18,705 个文件，最大资源 `ai-index.json` 为 22.59 MiB；仍保留接近当前文件上限的提示。Radio 的实际索引、主题队列、YouTube 优先选择、结束续播与清空停止均通过专项复查；播放器回调使用本地测试资料，真实平台播放仍待正常网络验收。正式共享服务的正常账号联调仍沿用 [上一批未完成事项](2026-10-14-archive-implementation.md)，不会因为接入开源组件而计为已经上线。
