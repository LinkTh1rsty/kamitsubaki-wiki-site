# Fan Archive 更新复查与 UI 调整（2026-10-13）

本次复查覆盖 Graph、Story Mode、Live Archive、Credits Database、Discovery Engine 和资料完善看板，参照现有探索目录、数据库页面及共享工作区组件检查交互与视觉一致性。修复随 [PR #72](https://github.com/LinkTh1rsty/kamitsubaki-wiki-site/pull/72) 提交，不作为生产发布记录。

## 已确认并修复的问题

| 问题 | 触发方式与原行为 | 修复结果 |
| --- | --- | --- |
| Story 语言链接丢失章节 | 打开指定章节后，语言链接仍使用无章节地址；旧测试使用了与实际导航不同的标记，未发现问题 | 使用实际语言菜单，同步当前章节；复制其他语言链接或无法保存本机进度时也能打开指定章节 |
| Discovery 换路线意外应用草稿 | 修改偏好但不提交，再点击“换一条路线”；原实现会读取新表单，甚至被尚未提交的无效起点阻止 | 只更换已应用条件的路线变体，保留未提交的表单；主动应用才改变偏好 |
| 资料看板无法返回上一组筛选 | 用下拉框换缺项或排序，再清除条件；原实现覆盖当前历史记录 | 下拉筛选、字段快捷入口和清除操作均保留可返回的历史；关键词输入继续更新当前记录 |
| Graph 清除高亮后按钮状态不符 | 显示连接路径后清除高亮；画布已清除，路径按钮仍标记为按下 | 同步清除路径按钮的 `aria-pressed`，显示状态与操作状态一致 |

前三个问题均先用回归测试复现失败，再验证修复；Graph 状态检查补入已有路径交互测试。演出与署名查询的筛选、分批展开、身份区分和统计口径也纳入复查。

语言查询统一使用[共享同步方法](../../../src/lib/localeQuery.mjs)。演出、署名和资料看板在切换语言时也保留当前筛选；Graph 与 Discovery 使用同一方法，减少各功能导航标记不一致的问题。

## UI 调整

- Story 的已读主操作、媒体控制、上一章／下一章、分享与重置复用 `WorkspaceButton`，主操作使用全站一致的实心样式，重置降低视觉权重。
- Story 路线卡片统一表面颜色、内边距和标题大小，编号缩小，入口增加分隔线与既有 Lucide 图标；续读文字更新时保留图标。
- Discovery 的按钮与输入框使用共享控制尺寸、颜色和圆角；简化偏好表单与每日路线的重复外框，当前站仍有明确标记。
- Graph 过滤器复用 `WorkspaceFilters`，操作按钮复用共享组件，缩放和交换端点使用现有图标；路径查询区改为分隔线组织，减少嵌套外框。
- Graph 与 Discovery 的手机统计区修正右侧多余边框；窄屏输入框保持可读字号。资料看板的字段按钮使用统一控制圆角。

调整保留可交互图形、档案卡片和需要操作的控件边界；普通说明与分组继续遵循全站以文字、留白和分隔线组织内容的方式。
