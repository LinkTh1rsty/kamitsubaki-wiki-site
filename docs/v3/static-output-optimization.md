# 静态产物优化与旧网址移除

2026-09-20。用户确认不需要保留旧分享地址，V3 继续采用纯静态 Pages，不新增重定向 Function。

## 路由规则

- 移除五语言下 `/artists/`、`/projects/`、`/songs/`、`/albums/` 的旧百科页面及旧音乐索引重定向。旧地址返回 404。
- 当前词条使用注册表生成的 `/[locale]/database/.../` 规范地址。首页、音乐导航、LABs 和编辑提示均使用新地址。
- 根路径、语言域名及其他功能的少量重定向仍保留；这次移除范围是旧百科集合网址。
- 历史迁移映射保留用于内容引用解析及审计，不再生成公开兼容页面。原始 Markdown 不改写；渲染时将可准确识别的旧引用转换为规范链接，不能唯一识别的引用保留文字并标注链接待补全，禁止猜测目标。

## 实测结果

| 项目 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 部署文件 | 24,453 | 15,068 |
| 构建页面 | 18,829 | 9,444 |
| 可索引规范页面 | 9,330 | 9,330 |

减少 9,385 个文件，约 38.4%，距默认 20,000 文件上限还有 4,932 个。最大单文件仍为 `ai-index.json`，21.22 MiB。

全量生成 HTML 和五语言索引检查：9,446 个 HTML 文件、9,445 个去重站内目标，缺失目标 0，已停用的百科网址引用 0。渲染结果中仍有 253 处待补全引用（包含语言版本重复），属于内容维护待办，不能视为内容完整性已经验收。

类型检查：0 errors、0 warnings。完整前端测试仍有已知歌曲目录规则失败，未隐藏或跳过；本次链接转换专项测试通过。

内置浏览器已验证 LABs 音乐入口进入新数据库，旧歌曲地址显示站内 404。未删除图片或词条，未发布前台。

## 维护与检查

- `pnpm build`：构建规范页面。
- `node scripts/v3/check-built-links.mjs`：扫描全部生成 HTML 与索引，缺失目标或旧百科网址会阻断 CI。
- `node scripts/audit-pages-assets.mjs dist`：统计文件与目录；默认 18,000 文件预警、超过 20,000 阻断，同时检查单文件体积。
- `node scripts/sync-docs.mjs --check`：检查工作区文档镜像。

不要重新加入每条词条的旧路径静态重定向页面。新增链接通过注册表或规范路径生成。其他发布条件沿用 [全站 QA 记录](acceptance/full-site-qa-2026-09-20.md)：歌曲目录规则、真实云端投稿与审核验收等仍需独立完成。
