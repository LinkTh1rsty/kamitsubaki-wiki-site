# Credits Database｜创作者署名查询说明

Credits Database 从歌曲的明确制作署名生成创作者索引，方便查看某位创作者参与了哪些已收录作品、担任哪些角色、与哪些演唱者合作，以及有日期作品的年份分布。

入口：`/zh/explore/credits/`。已被歌曲署名关联的创作者词条也有相应查询入口。

## 已完成的功能

- 创作者目录，展示已记录作品数量与角色。
- 创作者、演唱者、署名角色、年份和关键词组合筛选，支持排序和分批展开。
- 创作者概况展示作品总数、角色、合作艺人与年份分布。
- 点击合作艺人或年份可缩小下方作品列表。
- 作品卡片链接原歌曲；已关联实体的创作者可进入人物词条。
- 分享地址保存查询条件，浏览器前后退可以恢复。

## 使用方法

1. 在创作者目录选择一个名字。
2. 先看概况，再选择演唱者或制作角色，例如“花谱 + 作曲”。
3. 需要时加年份或关键词，打开歌曲核对完整署名和来源。
4. 从歌曲继续查看其他制作人员，或带着创作者身份进入 Graph。

示例：

```text
/zh/explore/credits/?creator=entity%3Akanzaki-iori&artist=kaf&role=composer
```

该查询选择关联到カンザキイオリ实体的署名组，筛选明确记载其担任作曲且花谱为演唱者的歌曲。

## 身份与统计口径

索引只读取歌曲的 `credits`，不把正文提到的名字或组织所属直接认定为制作署名。

有实体 ID 的创作者按稳定 ID 编组；只有文字姓名的署名按已填写姓名单独编组，不自动合并到同名人物。同名不一定同人，名称写法不同也可能需要人工核对后才能统一。只有文字姓名的署名组可以查作品，但不会获得虚构的人物页面。

同一首歌里同一创作者担任多个角色，合作作品数只计一首；查询“创作者 + 角色”时，两项必须出现在同一条署名上，不能拿另一人的角色凑成匹配。合作艺人来自歌曲明确的演唱者记录。

创作者上方概况统计其全部已收录署名作品，下方作品列表才应用当前筛选。因此加上某位演唱者后，上方总数可能大于下方结果数。年份分布只统计已记录发行日期的作品，不猜测未知日期。

## 当前覆盖与限制

2026-10-13 候选资料中有 1,557 首歌曲，其中 153 首具备非空制作署名；这些署名形成 39 个创作者组，3 个已关联人物实体。数字随资料补充与构建变化。

目前查询覆盖取决于结构化署名的完整度。页面中的合作数量表示“本站已收录”，不能据此断言神椿历史上参与作品最多的创作者或完整合作总量。作曲、作词等缺项需继续补充。

本轮完成的是署名查询、概况与作品关联；完整创作者人物档案、所有 MV／插画／设计作品的统一索引，以及基于完整资料的历史排名仍需推进。

## 维护入口

在歌曲 `credits` 中填写角色、姓名及可确认的实体 ID，并记录来源。先核对身份再合并署名组；多角色可以保留多行，不需要为了统计人为删掉角色。公开并重新构建后会自动进入索引。
