# Story Mode｜交互式入坑路线说明

Story Mode 把已有档案编排成分章导览，为新人提供“先看什么、为什么看、接下来往哪里走”的阅读顺序。每章有目的、引导问题和可打开的资料，歌曲、视频、人物、演出与 Chronicle 可以在同一条路线里出现。

入口：`/zh/explore/stories/`。首页、探索目录、相关词条和既有世界观导览也提供入口。

## 本轮提供的五条路线

| 路线 | 建议时长 | 地址中的路线 ID | 阅读目标 |
| --- | --- | --- | --- |
| 第一次认识花谱 | 20 分钟 | `first-kaf` | 从声音认识歌曲、创作者、舞台与团体 |
| V.W.P 是什么 | 30 分钟 | `meet-vwp` | 认识团体、成员、作品与活动 |
| 神椿市世界观 | 45 分钟 | `kamitsubaki-city` | 从企划、游戏、人物与媒体找到原作入口 |
| 从花谱到廻花 | 25 分钟 | `kaf-to-kaika` | 沿已记录的关联认识两个独立档案 |
| 从 PIEDPIPER 认识神椿 | 30 分钟 | `from-piedpiper` | 从制作人与组织理解所属和作品署名 |

每条路线六章。建议时长用于安排导览阅读；完整播放歌曲、视频或阅读原作所需时间另计。

## 阅读与进度

1. 在目录选路线；读过的路线会显示已有进度，可继续阅读。
2. 阅读当前章的目的和问题，打开资料卡，或按需加载已有媒体。
3. 阅读完成后点击“读完本章”，保存完成状态并继续。
4. 可以返回上一章、直接选章或先看下一章，这些操作不会自动标记已读。
5. 全部六章明确完成后显示完成面板，提供其他路线、Discovery 和 Graph 入口。

播放器点击后才加载，不自动播放；关闭或切换章节时停止嵌入播放。原媒体链接一直可打开。世界观摘要默认折叠，用户可以自行展开。

已读状态保存在当前浏览器，五种语言共用稳定的路线和章节 ID。刷新可续读，换设备或浏览器不会自动带走进度，目前没有账号云同步。浏览器禁止保存时，本次仍可继续阅读，并提示无法持久保存。

“重新开始”只清除当前路线的进度。选材身份或媒体发生变化时，旧进度会因路线指纹改变而重置，避免把已更换的资料误当作读过。

## 分享章节

```text
/zh/explore/stories/first-kaf/
/zh/explore/stories/first-kaf/?chapter=listen
```

第一个打开路线并按本机进度续读；第二个明确打开“把名字变成声音”这一章，优先于本机保存的位置。分享只包含路线与章节，不包含自己的已读状态。接收者仍保留自己的进度。

没有脚本时，全部章节、资料和原媒体链接仍可阅读；脚本加载失败时保留内容并提供重载入口。

## 选材依据与当前限制

路线目的、提问和顺序由编辑编排，材料在构建时从当前档案解析。成员沿明确所属关系选择，歌曲沿演唱署名选择，创作者沿制作署名选择，演出仅使用符合类型的明确出演记录，Chronicle 使用已有实体引用。

某些章节是编辑推荐的独立阅读材料，会与事实关联区分。导览顺序不表示作品共享同一剧情时间线，也不会因为把两份材料放在一起而新增制作署名或关系。

媒体读取既有结构化字段以及正文明确的媒体指令、视频链接，排除代码和注释。只有名称但没有实体 ID 的署名不会自动生成创作者人物关系。缺少材料时如实显示缺项，需通过补充档案解决。

本轮完成五条导览及阅读交互；仍可继续增加路线、优化选材和完善媒体资料。完整第三方播放体验取决于媒体提供方，嵌入控制检查不等于所有视频均已完整播放验收。

## 维护入口

新增路线先编写学习目标、章节 ID、提问与选材规则，再检查各语言材料身份和既有入口。资料补充依旧在原词条完成，避免复制一份无法同步的正文到导览中。
