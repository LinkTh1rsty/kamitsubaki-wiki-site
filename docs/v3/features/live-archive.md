# Live Archive｜演出档案馆说明

Live Archive 将已有活动实体整理成可筛选的档案目录，并在活动与歌曲之间建立可核对的演出记录入口。它解决“某位艺人参加过哪些已收录活动”和“这首歌有哪些已记录演唱”的查询问题。

入口：`/zh/explore/lives/`。点开活动卡片后进入原活动词条；有对应记录的歌曲也能查看反向演出历史。

## 已完成的功能

- 关键词、出演者、活动类型、年份和现实／虚拟／未标明场地组合筛选。
- 活动排序、分批展开、清除条件与地址分享，浏览器前后退可恢复条件。
- 活动详情展示已填写的日期、日期范围、场地、地区、主办、主要出演和嘉宾。
- Setlist 按原顺序展示，保留同曲重复演唱、返场编号、标题中的版本标注与自由填写标题。
- 有效歌曲 ID 连接歌曲词条，并形成歌曲页面的“已记录的演出历史”。
- 缺少曲目的演唱会可以进入资料完善流程；展览和一般活动不被分配演出曲目任务。

## 使用方法

1. 打开演出目录，选择艺人；需要时继续限制年份和活动类型。
2. 通过场地模式区分现实、虚拟和未标明的记录。
3. 打开活动，核对日期、出演者、场地和已收录 Setlist。
4. 点击有链接的歌曲，继续看歌曲资料及其他已记录演唱。
5. 复制带筛选参数的地址分享，或从实际词条编辑入口补充有来源的资料。

示例：

```text
/zh/explore/lives/?artist=rim&year=2021&mode=physical
```

这表示筛选明确记录理芽出演、覆盖 2021 年且场地标明为现实的活动；没有匹配记录时显示空结果，不补造活动。

## 数据怎么连接

档案以已有 `live-event` 实体为单位，出演者来自 `headliners` 和 `guestPerformers` 等明确字段。组合出演不会自动展开为每位成员各自出演。

Setlist 的顺序和标题来自 `setlist`。只有存在且指向歌曲实体的 `songId` 才形成歌曲链接；自由填写标题仍可展示，但不会靠名字相似猜测对应歌曲。没有原编号时不添加虚构编号。

歌曲的反向历史按活动 ID 去重，同一活动重复演唱会保留各次位置；最早已收录记录只代表本站已知范围，不认定为歌曲首次演唱。

日期按已记录精度展示。跨年范围可以参与覆盖年份的筛选，但一条活动记录不一定只代表一个独立公演场次；目录数量不能直接解释为举办场次总数。

## 当前覆盖与未完成的扩展

2026-10-13 候选资料中有 12 条活动记录，其中 8 条属于演唱会类型，尚无填写曲目的 Setlist。演出查询和 Setlist 展示能力已完成，歌曲历史需要补充实际曲目记录后才会有结果。缺少 Setlist 表示未收录，不表示没有演唱歌曲。

原提案中的票种、商品、报道、现场照片体系、观众贡献、首次演唱认定等完整档案能力，尚未在本轮逐项实现。现有页面只展示已具备的字段和原资料，不声称每场活动已经建成完整档案。

## 维护入口

补充演出应核对日期、场地与出演者，并给出可靠来源。填写 Setlist 时保存原曲序、重复演唱与返场信息；能确认歌曲身份时再填写有效 ID。内容经既有审核流程公开并重新构建后进入目录。
