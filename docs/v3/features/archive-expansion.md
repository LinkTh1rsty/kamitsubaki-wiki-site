# Fan Archive 扩展功能

更新：2026-10-14。以下为 `codex/fan-archive-roadmap` 的实现范围，尚未发布。原六项功能的历史说明继续保留；本页与[本次验收](../acceptance/2026-10-14-archive-implementation.md)记录后续增量。

## 入口与操作

下列路径中的 `zh` 可替换为 `en`、`ja`、`zh-tw` 或 `zh-hk`。探索门户按六个系统分组；实体阅读页也提供音乐、版本、到场、版次、证据和对比入口。

| 模块 | 入口 | 操作 |
| --- | --- | --- |
| F02 Atlas | `/zh/explore/atlas/` | 切换现实与虚拟地点，查阅坐标与关联。选择打开交互地图后才加载背景地图，可缩放与用键盘选择地点；背景不可用时保留标记和列表。添加、排序巡礼路线，打开导航，自愿记录去过的演出。虚拟地点图显示关系，不表示真实地理距离。 |
| F04 Music / Genome | `/zh/explore/music/` | 按演唱者、创作者、年份、角色与标签筛选，展开版本与署名、媒体及演唱历史。二维使用年份和时长；三维增加已记录 BPM，可旋转观察。缺坐标的作品不绘制。 |
| F05 Live Mode / Witness | `/zh/explore/live-mode/` | 查看记录的公告、场地、交通、票种、商品与报道。到场记录默认私人；自行选择公开后可在演出详情展示，随时移除或改为私人。票根链接亦遵循该选择。 |
| F06 Visual / Museum | `/zh/explore/visual/`、`museum/` | 按记录日期浏览形态、设计与用途；拖动年份筛选。选择图片可放大、浏览下一张和查看资料；无初出日期的视觉明确显示未记载，发行日期不替代视觉初出日期。展馆可阅读经过审核公开的社区展览。 |
| F08 Statistics | `/zh/explore/statistics/` | 公共年度趋势、已记录时长、制作署名、Setlist 频次和样本中最近明确日期。重复曲目条目与演出次数分开统计。 |
| F10 Observatory / Passport | `/zh/explore/observatory/` | 听过、已读、去过、拥有与守护记录，兴趣、印章、探索成就、个人年度回顾。导出/导入私人记录；登录后同步。主动公开护照时仍只展示单独选择公开的记录。 |
| F10 Collections / Exhibition | `/zh/explore/collections/` | 按实体 ID 编排顺序与章节笔记；保存草稿、公开集合、关注/取消关注、复制为自己的草稿。展览先提交审核，由独立审核者决定公开。 |
| F11 Challenges | `/zh/explore/challenges/` | 从实际缺项与缺译生成任务，认领、释放、提交投稿链接。审核者检查有效成果后批准；月度贡献与贡献成就只计算真实批准状态。 |
| F13 Radio | `/zh/explore/radio/` | 从 806 首具备已记录播放器的歌曲建立艺人、年代或创作者队列。手动播放；YouTube 结束时继续下一首。通过独立播放窗保持跨页面播放；队列与播放进度存于此设备。 |
| F14 Ask | `/zh/explore/ask/` | 输入问题，检查并修改识别出的实体、艺人、年份、角色、类型等条件，再确认执行。分享链接保留确认后的条件。结果连接证据、Graph 和 Chronicle；当前支持有限查询文法。 |
| F15 Compare | `/zh/explore/compare/` | 并列选择实体，查看数量、共同关系与各自关系；也可并列比较年份。零条已录入关系显示为零，未知日期显示未记载。 |
| F16 Evidence / History | `/zh/explore/evidence/` | 查看具体字段与具体来源的证据图、核对状态、修订历史和已填写的历史页面元数据。外部保存搜索链接不表示已经验证某份网页存档。 |
| F17 Languages | `/zh/explore/languages/` | 查看原始译文覆盖、共享事实、术语及事实差异，进入对应翻译任务。繁体版本注明转换生成；叙述缺译保留回退提示。 |
| F18 Rooms | `/zh/explore/rooms/` | 创建/加入房间，主持人选择实体、时间轴事件或公开集合。参与者选择跟随主持，在页面内阅读当前位置；在线参与状态定期刷新。只有主持人能改变共享位置。 |
| F19 Physical / Scanner | `/zh/explore/physical/` | 浏览发行版次与独立实体物品、特典差异。手动输入或允许相机扫描，优先使用浏览器原生识别，再使用软件解码；停止、识别成功、离页或切到后台时释放相机。校验条码、匹配已记录物品，由用户确认加入拥有记录。 |
| C01 Today | `/zh/explore/today/` | 按月日查历史事件，只有精确到日的日期参与匹配；每日猜档案使用实际元数据。首页提供历史上的今天，Chronicle 提供五个主题预设及日期区间。 |

Story Mode 扩展为七条六章导览，新增神崎伊织创作线与舞台阅读线，并连接 Chronicle。Credits 查询现在也纳入发行等作品的署名，歌曲覆盖仍单独统计。Support 首屏增加自愿支持、内容贡献及年度摘要入口；未知账目继续显示待公布。

## 实体导航与开源组件

人物、歌曲、专辑及演出正文前的档案导航显示实际收录数量与关联链接。歌曲和演出按稳定实体身份去重；制作署名、专辑曲目和 Setlist 明确标为条目数。公开图片计数来自图库的公开结果，读取失败仍显示未知。

交互地图使用 [Leaflet](https://leafletjs.com/)，软件条码解码使用 [ZXing](https://github.com/zxing-js/browser)，图片查看复用现有 [PhotoSwipe](https://photoswipe.com/)。地图按读者选择加载，保留背景地图署名，巡礼连线仅表示选择的地点顺序。地图背景遵循提供方的使用规则，不提供批量下载或离线预存；默认提供方规则见 [OpenStreetMap](https://operations.osmfoundation.org/policies/tiles/)。相关许可证随站点提供于 `/third-party-notices.txt`。

Radio 与音乐详情复用正文已声明的媒体短代码及显式媒体字段；普通外链、注释和代码示例不会进入播放索引。当前 806 首歌曲具备可嵌入播放器，共享相同资料供筛选和队列使用。

## 资料与共享服务边界

本次样本包含 1,836 个实体、1,557 首歌曲、154 首非空署名歌曲、518 个时间轴事件、12 个活动。新增 1 条有官方依据的 Remix 版本关系、1 场演出的 7 个 BD 歌曲章节摘录、1 个核对坐标、1 份有日期的视觉使用记录、4 个专辑版次及 1 件独立 BD 物品、25 条字段证据。演出曲目明确标注为部分摘录，不是完整现场 Setlist。

Genome 二维当前有 1,472 首具备年份与时长的作品；三维 BPM 与可匹配条码目前为零条。界面支持这些资料，但不使用估计值填补。旧译文中发现的 42 处事实差异保留为待核对问题；跨语言结构化查询已使用同一份事实，译文不会覆盖它。

个人设备记录、公共档案查询与播放队列可以独立使用。账号同步、公开集合、审核、护照、公开到场记录和房间需要配置共享服务并进行正常账号联调。本轮已提供服务实现与本地运行检查；这些检查不能替代正式站点的登录、投稿、审核和账号切换验收。

## 维护

用 `pnpm archive:check` 检查身份、关系、字段证据、资料契约及实体物品。事实字段集中在 `src/lib/sharedEntityFacts.mjs`；名称、摘要与正文保持分语言。新 `sourceIds` 必须指向同一实体的已记录来源，不能用页面来源列表自动证明所有字段。

公开接口与引用方法见 [Open Data](open-data.md)。来源补齐后重新校验、生成需要保留的快照并构建。资料贡献沿用现有投稿流程；领取任务和赞助均不自动取得编辑或审核权限。
