## 可审核的变化

- `/zh/contribute/edit/` 分为站内编辑器版与 GitHub 流程版。站内版解释登录、选词条、写作、草稿、差异、投稿和跟进；GitHub 版解释 Fork/分支、文件修改、PR、检查和部署。修正三种源语言 FAQ 中过时的账号及草稿说明，生成繁中版本。
- 切换指南不重载页面，URL 记录所选流程，浏览器返回可还原。旧教程锚点仍会展开对应教程；目标文件继续传给编辑器。
- 正文工具栏加入无序/有序列表与缩进控件。支持 `-`、`+`、`*` 后加空格，以及 `1.` / `1)` 后加空格；中文输入法组合输入期间不转换。支持标题和引用标记。
- 正文 Enter 分段，Shift+Enter 保留换行；列表 Enter 续写、空项 Enter 退出、Tab/Shift+Tab 调整层级。斜杠菜单提供独立的两种列表，空块插入时不多留一个空块。
- 列表 Markdown 导出兼容 Chrome 的直接嵌套列表 DOM，保留有序列表起始编号。旧草稿中的列表块自动转为可直接编辑的富文本格式。
- 修复输入后立即撤销失效的问题；撤销/重做后焦点留在正文。格式按钮在光标移动时更新状态。
- 词条选择结果提供类型筛选、多关键词匹配、结果总数、50 条上限提示、失败重试及键盘选择。长标题和路径在侧栏内换行。
- 统一首页账号入口与 LABs/搜索/菜单的尺寸和圆角规则；调整编辑块、侧栏按钮、选择卡片与窄屏工具栏。修正投稿提示条导致手机侧栏重复下移的问题，并增加侧栏关闭按钮、移动端命令按钮及外观选项的可访问名称。

交互参考：[Notion 写作与编辑基础](https://www.notion.com/help/writing-and-editing-basics)、[键盘快捷键](https://www.notion.com/help/keyboard-shortcuts)。沿用 Wiki 的主题与 Markdown 数据格式，没有引入 Notion 数据库或多人实时协作。
