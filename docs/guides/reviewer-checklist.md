# 投稿审核清单

## 共通检查

- 投稿者、内容类型、目标语言和审核权限明确。
- 变更只包含本次范围；没有覆盖其他语言、原正文或无关文件。
- 事实有可访问来源，直接引文、图片、歌词和媒体符合许可与署名要求。
- 不包含个人隐私、令牌、本机路径、临时 `blob:` 地址或未公开暂存资源。
- 待审版本与当前公开版本的差异可读；冲突时要求基于最新版本重新提交。

## 百科词条

- 搜索过名称、别名和稳定 ID，没有重复建档。
- `schemaVersion: 2`、`id`、`locale`、`entityType` 与类型必填字段通过校验。
- 三个源语言共享实体身份和结构关系；未翻译内容没有伪装成已完成译文。
- 人物、团体与企划符合分类地图；歌曲目录来自 `performers`，唱片目录来自 `releaseType`。
- `relations`、`performers`、`credits`、`affiliations` 指向实际 ID；两端阅读器联动合理。
- `presentation` 的图片、主题和形态组不会破坏背景、资料卡或选择器。
- 正文保留已有内容，新增段落有信息价值；参考资料和外部链接使用统一组件。

## 文章

- 标题、语言、分类、摘要、正文和关联词条正确；观点与事实有清楚边界。
- 草稿和退回版本只对作者/管理员可见，批准前不会覆盖公开文章。
- 编辑器预览、公开阅读器、目录、关联档案和引用在批准后正确。
- 文章图片使用可长期读取且具备许可的网址；不要把百科 GitHub 附件误认为文章上传功能。

## 图库

- 角色已选择，文件类型与大小合规；SVG 和可执行内容被拒绝。
- 来源、作者、日期和形态虽可后补，但已有资料必须准确，不制造版权结论。
- 新图在私有暂存状态；批准后才进入公开图库。暂存预览只对作者和管理员开放。
- 修改提案以当前公开版本为基准；批准前继续显示旧版，冲突不能静默覆盖。
- 隐藏/恢复、审核意见和管理员操作写入审计记录。

## 审核完成

记录批准或退回理由、检查环境和必要证据。百科要等 PR 合并和站点更新；文章、图库要等审核通过并在公开页面可见。界面显示“提交成功”只表示提案已收到。
