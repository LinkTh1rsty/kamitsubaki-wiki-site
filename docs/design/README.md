新页面必须先套用共享页面结构和组件，再增加本功能真正需要的交互。导航、返回按钮、主操作的位置保持一致；动效表达状态变化，不为装饰引入无关滑块。验收时同时检查明暗主题、窄屏、键盘、减少动态效果和刷新稳定性。
