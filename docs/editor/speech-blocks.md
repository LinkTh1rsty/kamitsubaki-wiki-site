# 发言块与快速导入

文章和词条使用同一套功能。桌面使用署名边栏，手机将头像和名字放在正文上方；颜色只作辅助识别，发言始终显示名字。

## 编辑

1. 在写作导航的「本文参与者」添加站内人物或自定义角色。绑定人物会带入词条链接和头像；显示名称、头像、颜色可单独修改，不会修改人物词条。
2. 将光标放在目标段落，点击「发言」，选择角色并填写正文。一个发言支持多个段落和已有 Markdown 内容。
3. 修改参与者会统一更新当前文档中使用该角色的发言。

## 快速导入

点击「快速导入」，粘贴 `姓名：正文` 文本，或上传 Markdown / 文本文件，再点「识别发言与角色」。未标明角色的行保留为普通段落，不自动猜测发言者。多段回答请用模板。

检查每个角色：可绑定站内人物、保留自定义角色，或选择「对应本文角色」复用已有角色。导入不会仅凭同名覆盖已有角色。预览后点击「插入」，片段插入当前段落之后，可一次撤销。取消不会修改文档。导入期间若原文已变化，会要求重新打开以避免错位。

窗口提供「下载模板」和「复制 AI 转换提示词」。对应文件为 [模板](speech-template.md) 与 [AI 提示词](speech-ai-prompt.md)。AI 只用于外部格式转换，编辑器不会自动将内容发给 AI。

## 源码格式

参与者保存在正文 `speech-roles` JSON 围栏内，而非文章专用属性；因此文章、人物和其他词条可以一致导出与重新打开。每个文档只保留一份角色配置。发言使用 `:::speech 角色标识` 开始，以独立的 `:::` 结束。角色标识与显示名称分离，改名不会改变发言对应。

无法闭合、嵌套或引用未知角色的导入会提示错误；普通代码示例不会被识别为发言。角色最多 64 个，单次导入最多 300,000 字符 / 1,000 个片段。头像支持站内路径、HTTPS 或现有图片上传流程；上传图片沿用原有附件来源和投稿校验。
