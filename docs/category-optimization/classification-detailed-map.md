## 五、 功能型数据集 (Feature Data) 独立架构展开

### 5.1 全景时间轴数据集 (Chronicle Feature Dataset)
存放于 `src/data/chronicle/{year}.yml`，包含以下四大叙事轨道：

- `project-verse`（企划宇宙与多媒体轨道）
- `isotope-synth`（同位体与合成声学轨道）
- `organization-biz`（组织架构与商业基建轨道）

### 5.2 设定资料图库数据集 (Reference Gallery Feature Dataset)
存放于 `src/data/galleries/{subject}.yml`（根级 `subject` 必须引用合法的 Entity ID，如 `kaf` 或 `kamitsubaki-city`），包含六大受控维度：
- 角色实体 (Characters - 引用 Entity ID，角色类设定图必填，非角色场景/建筑图可选)
- 形态版本 (Form - 全局唯一带角色前缀 ID，如 `kaf-default-v1`, `kaf-kaika`, `rim-default-v1` 等；非角色视觉资料可选)
- 设计标签 (Tags - character-sheet, costume, front-view 等)
- 公开时期 (Date)
- 贡献录入者 (Uploader)
- 考据备注与出处证据 (Notes & Source - 来源支持 URL 或实体出版物 title + page)
